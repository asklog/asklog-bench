# model-testing

A sandbox for trying new models by having them build small HTML apps, to test their UI ability.

## Models

- Kimi K3.1 Pro (OpenRouter id: `moonshotai/kimi-k3.1-pro`) - first model under test

## Running

Run with `op run --env-file=.env.op -- opencode` (injects the OpenRouter key from 1Password).
