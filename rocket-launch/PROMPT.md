```text
Build "ASCENT", a single-page rocket launch simulator. Scene: a procedurally drawn two-stage rocket with a payload fairing (SVG or canvas, no image files) standing on a launch pad with a service tower and umbilical arms, at dusk with distant terrain. Launch control panel in a polished mission-control style: a pre-flight checklist of 6 items (Range clear, Weather go, Propellant load, LOX load, Guidance internal, Flight termination armed) that the user confirms one by one, each with an animated GO confirmation; the propellant steps visibly fill the tank gauges, and the launch button stays locked until every item is GO. A throttle control (60-100%) that changes thrust, flame size and acceleration in real time. A T-10 countdown with large animated digits, venting vapour from the rocket during the count, and the umbilical arms swinging away at T-3. Ignition at T-0: an engine flame with a bright flickering core, additive glow particles and shock diamonds; billowing smoke that spreads sideways along the pad and lingers; screen shake that scales with thrust and fades with altitude. Ascent: a simple but plausible simulation (thrust, mass dropping as propellant burns, gravity, drag that falls with air density, a MAX-Q callout) with a gentle gravity turn that tilts the rocket; the camera follows the rocket. Parallax sky: ground, several cloud layers the rocket punches through, a sky gradient that shifts from day blue through deep indigo to black space as altitude rises, stars fading in, and the curve of the Earth appearing at the end. Staging: when stage 1 runs dry, MECO, the spent stage separates and tumbles away with a fading flame, a separation puff, then second-stage ignition; later the fairing splits into two halves that drift away; finish with an orbital insertion banner and a mission summary (max altitude, max velocity, max g, mission time) plus a Reset button. Live telemetry: altitude, velocity, fuel per stage and g-force as animated gauges (dials and bar meters), a small altitude-over-time line chart, a T+ mission clock, and an event log (Liftoff, Max-Q, MECO, Stage separation, Second-stage ignition, Fairing separation, SECO, Orbit). Controls: an Abort button during ascent that triggers a dramatic launch-escape sequence for the capsule, time warp (1x / 2x / 4x), and a mute toggle. Sound is optional; if included, synthesise it with Web Audio (countdown beeps, rumble) and start it only after a user gesture. On phones the control panel becomes a bottom sheet and the telemetry compacts; mouse, touch and keyboard all work (Space advances the checklist and launches). Hard requirements: put everything in ONE self-contained index.html file - no build step, no npm, no bundler, no other files. External JS/CSS libraries only via <script>/<link> tags from cdnjs.cloudflare.com, cdn.jsdelivr.net or unpkg.com; web fonts from Google Fonts are fine. No external images, 3D models or audio files: generate everything procedurally (SVG, canvas, WebGL, Web Audio). It must look premium and intentional, work from 360px phone width up to a large desktop with mouse, touch and keyboard, respect prefers-reduced-motion, run smoothly at 60fps on a laptop, and open straight from the file system with zero console errors. Work efficiently: plan briefly, then write the complete file in one go; do not scaffold, install packages or start servers. After writing, re-read the file once, fix any real bugs, and stop with a short summary of what you built and anything you cut. Write everything to rocket-launch/<model-folder>/index.html.
```
